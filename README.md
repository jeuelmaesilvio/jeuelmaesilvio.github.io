# Jeuel Mae Silvio — Portfolio

Personal portfolio site, published with GitHub Pages at https://sheweemae.github.io

- `index.html` — the whole site (HTML, CSS and JavaScript in one file)
- `portrait.jpg` — hero photo
- `resume.pdf` — opened by the Resume buttons

Certificate pictures: add them under `certs/` and set each certificate's `img` path in the `CERTS` list inside `index.html`.
